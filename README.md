# AI 降重助手

一个包含前端单页与 Node 代理的简易降重演示项目，支持自定义 OpenAI 兼容站点、模型选择和每分钟 5 次的请求限流。

## 快速开始
1. 安装依赖
   ```bash
   npm install
   ```
2. 启动本地服务（默认端口 3000）：
   ```bash
   npm start
   ```
3. 浏览器访问 `http://localhost:3000` 打开前端页面。

## 功能
- 设置面板可录入站点、API Key，并通过代理获取模型列表。
- 支持 DOCX、Markdown、TXT 导入并智能分段；未配置接口时提供本地演示改写。
- 后端代理 `/api/models`、`/api/rewrite`，对每个 Key 强制每分钟 5 次限流，并透传上游错误。

## 注意
- `.doc` 暂不支持解析，请先转换为 `.docx` 或文本。
- 代理仅做演示，未持久化密钥，请部署时按需加固鉴权与配额。
